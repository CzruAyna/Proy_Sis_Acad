# Roadmap inicial

Las fases ordenan el trabajo y permiten validar el dominio antes de ampliar el sistema.

| Fase | Alcance |
|---|---|
| 0. Base | Repositorio, configuración local, backend y frontend mínimos, documentación y control de versiones. |
| 1. Núcleo académico | Carreras, planes, materias, prerrequisitos y periodos académicos. |
| 2. Oferta e inscripción | Aulas, docentes, paralelos, cupos y reglas R1–R8. |
| 3. Notas | Actas, calificaciones, cierre y correcciones auditadas (R9). |
| 4. Auxiliaturas y permisos | Postulaciones, selección y permisos temporales (R10–R13). |
| 5. Documentos | Plantillas LaTeX y generación de PDF. |
| 6. Experiencia y optimización | Interfaz completa, generación de horarios y mejoras de rendimiento. |

El alcance de cada fase se detallará antes de implementarla. Las reglas vigentes están en `REGLAS_NEGOCIO.md`.
