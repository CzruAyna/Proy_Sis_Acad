# Instrucciones permanentes del proyecto

Antes de analizar, editar, probar o compilar este proyecto, leer completo
`REGLAS_USUARIO.txt` en la raíz. Es el registro acumulativo de las reglas
expresas del usuario y se aplica a todos los agentes que trabajen aquí.

Conservar las reglas anteriores al incorporar nuevas instrucciones. No
modificar el backend para resolver un cambio de presentación. Consultar los
documentos de coordinación en `docs/` y dejar allí los requisitos pendientes
para el responsable correspondiente.

Para trabajo de backend o de datos institucionales, leer también
`docs/PARA_BACKEND_DATOS_Y_FUENTES.txt` y registrar qué fuentes originales,
documentos e imágenes necesita aportar el usuario y qué falta verificar.
